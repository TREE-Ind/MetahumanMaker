# Documentation media

These are small rendered images and UI captures from actual local MetaHuman Maker workflows. They illustrate the add-on; they are not distributed character projects, native DNA, reference libraries or reusable texture atlases.

- `hero.jpg`: four-character launch montage: Orc, artist-outfitted Genie, Warrior and Alien.
- `blender-workflow.jpg`: Blender Anatomical body preview and controls.
- `agent-workflow.gif`: condensed recorded Blender MCP body edits and revision/check loop.
- `skin-reconstruction.jpg`: matched source/generated Orc UV-region comparison.
- `skin-maps.jpg`: albedo/normal/cavity/roughness breakdown, with display-contrast disclosure.
- `genie-expressions.jpg`: upper-body neutral/smile/raised-brow native captures with the artist's outfit.
- `unreal-editable.jpg`: native Creator editing of the delivered photo character.
- `tree-mark.svg`: TREE brand-mark paths from the company's official website, used to identify this project.
